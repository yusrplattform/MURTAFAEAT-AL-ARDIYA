# مرتفعات العارضية للتجارة والمقاولات

موقع عربي متجاوب لخدمات التطوير العقاري والوساطة العقارية والتثمين العقاري.

## التشغيل على Windows

1. ثبّت Node.js إصدار 22.13 أو أحدث.
2. اضغط مرتين على `START.cmd`. يثبت المتطلبات عند الحاجة، ويجهز قاعدة البيانات المحلية، ثم يفتح الموقع في المتصفح.
3. أبقِ نافذة التشغيل مفتوحة. اضغط Ctrl+C لإيقاف الموقع.

العنوان المحلي: http://127.0.0.1:5173/

## المحتوى والإعدادات

المصدر في مجلد `site`. بيانات الشركة والخدمات والأسئلة الشائعة في `site/lib/content.ts`.

راجع [دليل التعديل العربي](site/README-AR.md) لتعديل الصور والمحتوى والتواصل والاطلاع على تفاصيل النماذج.

يشمل الموقع صفحات الرئيسية، من نحن، الخدمات، المشاريع، طلب الخدمة، التواصل، المدونة، الخصوصية وشروط الاستخدام. لم تُدرج مشاريع أو بيانات تواصل غير مقدمة.

تُحفظ طلبات النماذج محليًا عند تشغيل الموقع محليًا. بيانات الطلبات المحلية وملفات الإعداد الحساسة غير مرفوعة إلى المستودع.
