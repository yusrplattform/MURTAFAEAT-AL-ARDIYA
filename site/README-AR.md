# مرتفعات العارضية للتجارة والمقاولات

موقع عربي باتجاه RTL مبني على React وVinext، مجهز لاستضافة Sites.

## تعديل الموقع

- بيانات الشركة والهاتف والبريد والعنوان وأوقات العمل وروابط التواصل: `lib/content.ts`، ضمن `company`. ضع رابط واتساب كاملًا مثل `https://wa.me/` متبوعًا بالرقم الدولي الصحيح.
- المحتوى والخدمات والأسئلة الشائعة: `lib/content.ts`. الأقسام الأخرى: `app/site.tsx`.
- الألوان والمسافات والتجاوب: `app/globals.css`.
- الصور: `public/architecture.jpg` و`public/detail.jpg`. الصور توضيحية وليست مشاريع للشركة.
- المحتوى مفصول عن العرض لتسهيل إضافة قاموس إنجليزي ومسارات لغات لاحقًا. لا توجد نسخة إنجليزية حاليًا.

## الطلبات

النماذج ترسل إلى `/api/requests` وتُحفظ في قاعدة D1 بجدول `service_requests`. لا يُرسل بريد إلكتروني تلقائيًا لأن بريد الشركة غير مقدم. يمكن الاطلاع على الطلبات باستخدام أدوات قاعدة بيانات Sites المتاحة للمالك. لا يوجد مسار عام لقراءة الطلبات.

الحماية تشمل تحققًا على الخادم، وحدًا لحجم الطلب، وحقلًا مخفيًا، ومدة دنيا للإرسال، والتحقق من المصدر، وحدًا من 5 محاولات في الساعة لكل معرّف شبكة مجزأ. هذه حماية أولية؛ يمكن إضافة تحقق بشري لاحقًا عند فتح الموقع للجمهور.

يجب اعتماد بيانات التواصل وأوقات العمل وسياسة الاحتفاظ بالبيانات قبل الإطلاق العام. سيظهر الاتصال وواتساب تلقائيًا بعد إضافة بياناتهما، وتظل أزرار التواصل وطلب الخدمة متاحة قبلهما.
